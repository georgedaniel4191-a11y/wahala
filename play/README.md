# Wahala — playable browser edition

A complete static Nigerian social mystery game. Open `index.html` in a browser or deploy the `play/` directory as a static site.

- 3 self-contained fictional mystery episodes, 5 characters each.
- Solo with 4 disclosed computer-controlled characters.
- Same-device pass-and-play for 2–5 humans with computer-controlled seats filling unused slots.
- Private role dossiers and missions, one choice per investigation round, three rounds, a midgame twist, reveal or conceal evidence, sealed ballots, accurate causal recap, scoring and persisted local progress.
- No accounts or backend needed for this edition. No online multiplayer. The Socket.IO game in `client/` + `server/` remains the separate online private-room implementation and requires a persistent server.

This edition is client-side practice and local party play, not a secure competitive online match. Case truth is authored and locked for each episode, while receipt availability, players and bot votes vary.
